# 已完成任务清理

在 DSH 原生子智能体面板的 **共享任务** 中，为已完成任务增加 **移除** 按钮。单击立即执行，不弹出二次确认；处理中防止重复点击，失败原因显示在任务行下方。

## 安装与使用

本版仅支持 **DSH 0.2.2-rc.2**。在“插件 → 添加插件”中输入：

```text
dsh-team-model-policy
```

沿用旧包名是为了让已安装用户通过 DSH 原生 **版本 → 检查更新** 升级。插件显示名称从“团队模型策略”改为“已完成任务清理”，功能已精简。

1. 在主会话中启用 DSH 原生 Agent Teams，并打开标题栏的子智能体面板。
2. 在共享任务列表中找到已完成任务，点击其右侧的“移除”。待处理和进行中的任务没有此按钮。
3. 移除会提交原生任务删除事件，从当前列表消失，历史仍保留。无需模型请求，不读取队员会话历史。

任务详情仍可展开查看说明、负责人和依赖。按钮跟随浅色、深色主题；只读访问下不提供移除操作。

## 状态与依赖保护

操作在 Host 再次核对任务状态和用户点击的版本，再调用原生 `delete` 转换。任务被重新打开或版本变化时保留原任务并提示重试；任务被其他任务依赖时显示原因，不自动修改依赖图。重复移除已删除任务视为成功。仅主会话可执行本插件的命令。

用户可直接输入相同命令：

```text
/team-task-remove task-id revision
```

Agent 已有的原生 `team_task_update` 的 `delete` 动作仍可用；插件不添加模型工具或提示词。

## v0.10 到 v0.11 的变化

v0.11 只保留已完成任务直接移除。旧版的模型设置页、创建/切换队员工具、实时权限跟随、成员清理、名额补偿、自定义名册和会话历史读取均已退役。模型、成员名称、消息、恢复和运行名额全部由当前 DSH 原生功能处理。

需要为子智能体选模型时，使用原生子智能体模型授权和 `subagent` 的模型参数；原生授权快照与子智能体权限遵循 DSH 自身规则。旧版“固定团队模型”“授权动态影响已有团队”“权限实时跟随 Lead”不会继续执行。

升级不清空旧设置、模型选择存储或历史移除记录，不重写会话，不删除真实成员、任务或工作目录。已经归档的会话保持归档。旧版额外的隐藏与执行守卫不再运行；历史对象是否显示、能否恢复由新版 DSH 决定。没有继续需要的配置记录可保留在原处。

仅调用原生任务服务，不提供兼容旧版 Team 接口的包装，也不修改 DSH 核心文件。退役了之前可能放大峰值的冷队员历史读取路径；这不等于已经定位或解决全部 Host OOM。

## 禁用和卸载

禁用后恢复原生只读任务列表。已提交的删除状态保留在原生任务日志中；重新启用不会重新显示已删除任务。插件不创建定时器、后台轮询、独立数据库或新的网络端点。
